# 最新论文数据

本目录只保存当前 `manuscript/20261103` 所需的数据及来源记录；求解和绘图代码位于 `../paper_code/`。

- `cases/`：14个最终 MAT，Figure 3–7 共用。包含完整 rho/S/N 时间快照、质心、质量、在线统计，以及动力学在 t=0,1,10,20,30,40,50 的微观状态。所有原始 MAT 均按 SHA-256 校验，移动前后字节不变。
- `derived/`：从这14个结果重建的绘图数据、全域误差、四行波速表完整精度 CSV、汇总 JSON。生成物可重建，不能替代原始数据。
- `figure1/`：Figure 1 原始宏观 t=30、50 快照，供跨图一致性核查。新 `sign_macro` 在这两个时刻与之逐元素相同；Figure 1 和3绘图共享新宏观结果。
- `figure2/`：当前正式旧速度矩阵及全部441点的参数核查记录。原始旧单组扫描文件在可恢复归档内，不与修正后的14组结果混用。
- `diagnostics/`：原验证结果与整理后的独立入口验证。
- `logs/`：本批正式计算日志及状态记录。
- `provenance/`：原始源文件版本、结果哈希、配置、报告和补丁。原路径用于追溯，部分记录会出现旧目录名称；这些不是当前代码依赖。

两个指数结果（a=0.0005、0.0001，epsilon=0.01）原先因磁盘写入不足，由完整 T=50 检查点恢复。其原始文件保持原样，`read_completed_case.m` 在内存中统一读取结构，不重写或伪装原始文件。

正式实验参数为 dx=0.025、dt=0.001、dv=0.02、T=50；具体配置以每个 MAT 的 settings/params 和 `paper_code/config` 为准。Figure 2 为独立的旧扫描，详见其目录中的检查报告。

`.gitignore` 仍忽略大型 MAT/图片。它们已保存在本地，但没有擅自提交或推送，也没有把大型数据加入 Git 暂存区。
